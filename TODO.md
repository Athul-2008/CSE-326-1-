# TripNest — project outcomes

## 1. Travel budgeting application
- [x] Keep the assigned Travel Budgeting Tool topic: provide travelers one place to organize trip plans, destinations, itineraries, and travel costs.
- [x] Support browser-demo account registration, sign-in, and sign-out with basic validation; clearly state the sign-in is a local classroom demo and not secure authentication.
- [x] Let a user create, view, edit, and remove trips with a title, destination, date range, budget, currency, and notes.
- [x] Let a user add, view, and remove destinations/places; save trip destinations in the user's place collection.
- [x] Let a user add, view, edit, and remove dated and timed itinerary activities, with estimated and actual cost fields.
- [x] Calculate and show trip-level costs, budget progress, and estimate/actual information.
- [x] Provide trip search and upcoming/past filters, favorite controls, a share-friendly trip summary, and print output.
- [x] Keep the interface responsive, navigable, attractive, and beginner-readable.

## 2. Use taught CSE326 concepts
- [x] Build with separate plain `index.html`, `style.css`, and `script.js` files; avoid frameworks, build tools, and backend code.
- [x] Apply semantic HTML5 structure, accessible labels and controls, form input types, and browser form validation.
- [x] Apply CSS variables, selectors, box model, typography, focus/pseudo states, Flexbox, CSS Grid, and responsive media queries.
- [x] Use JavaScript constants/variables, data types, conditionals, functions, arrays, objects, loops/array operations, DOM selection/manipulation, and event handling.
- [x] Demonstrate email regular-expression validation, date/time handling, JSON conversion, and browser `localStorage` persistence.
- [x] Include a plain-language project guide mapping the implementation to CSE326 topics and explain the local-only demo limitations.

## 3. Preview and GitHub Pages handoff
- [x] Keep the site working as a static page and provide clear beginner instructions for previewing it and publishing its website files through GitHub Pages.
