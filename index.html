CSE326 topics used in TripNest
Syllabus unitCourse conceptWhere to see it
I–II · HTMLHTML5 structure, semantic sections, labels, forms, input types, accessible controlsindex.html — header, nav, main, sections, forms and labels
III · CSSCSS variables, box model, selectors, Flexbox, Grid, focus styles, media queries and transitionsstyle.css — :root, layout, focus and responsive rules
IV · JavaScriptVariables, constants, strings, numbers, conditions, functions, arrays and objectsscript.js — trip data, calculations and named functions
V · Interactive webLoops/array methods, DOM updates, events, form validation, regular expressions, dates, JSON and Web Storagescript.js — forms, search, itinerary and localStorage
VI · DevelopmentOrganized files, debugging, browser testing and GitHub Pages deploymentREADME.md — project map and beginner publishing steps
Why no Java? CSE326 here teaches browser JavaScript for interactive websites. Java and JavaScript are different languages; this static website uses JavaScript because that is what the syllabus covers for client-side programming.
Keep it honest: the email-only profile and trip records are stored in this browser with localStorage. There is no server, shared database, or secure user authentication.
